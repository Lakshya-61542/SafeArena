## 5. Fix after first run on Windows / Python 3.14
A user run on Windows showed many `ERROR`s and `unclosed database` warnings: `EventStore` used `with sqlite3.connect()`, which commits but never closes, so `events.db` stayed locked and temp-dir cleanup failed (Linux/Python 3.12 did not surface it). Fixed in `backend/events.py` (connections are now always closed) and covered by `test_every_connection_is_closed`, which was confirmed to fail on the old code.
